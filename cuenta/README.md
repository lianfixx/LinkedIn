# Estado del perfil de LinkedIn de Emi

| Archivo | Qué guarda |
|---|---|
| `perfil.json` | Configuración que lee `linkedin.py`: URL, lo observado del perfil, objetivos, `captacion_milla` (`true`/`false` sin comillas), balance de pilares, cadencia, formatos, tono, minutos de Emi por pieza y sus pendientes. |
| `voz.md` | Cómo escribe Emi en LinkedIn y sus correcciones. |
| `aprendizajes.md` | Lecciones de cada publicación (`linkedin.py aprender`). |
| `referencias.md` | Cuentas públicas de IA + Derecho que sirven de ejemplo de formato, verificadas. |
| `publicados.jsonl` | Lo publicado y sus métricas (`linkedin.py publicado` y `metricas`). Se crea con la primera pieza. |
| `diagnosticos/` | Revisión mensual con las capturas de Analytics que pase Emi. |
| `privado/` | Borradores, semanas y propuesta de perfil sin publicar. **No se sube a GitHub**: el repositorio es público. |

El resumen para la Matriz de Redes (`red/estado.json`) se regenera con `linkedin.py estado` cada vez que cambia algo de aquí.
